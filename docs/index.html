CAR = selisih return saham terhadap IHSG (%). “Pra” = dari sinyal pertama sampai sehari sebelum t0; “Hari-H” = t0 −1 sampai t0 +1. Isi data/outcomes.csv lalu jalankan workflow.

  1. Kumpulkan otomatis tiap 3 jam oleh GitHub Actions: Google News RSS (frasa sumber anonim, aksi korporasi) dan RSS media.
  2. Deteksi frasa seperti “menurut sumber” dan tanggapan manajemen (membenarkan, membantah, tanpa komentar).
  3. Petakan ke emiten lewat data/emiten.csv (nama, alias, kode dalam kurung).
  4. Skor 0–100: reputasi media, jumlah frasa sumber, pihak disebut, nilai transaksi, jadwal, korroborasi media lain 7 hari, tanggapan 3 hari.
  5. Catat hasil: tambah baris di data/outcomes.csv (ticker, t0, status). Lead time dihitung otomatis.
  6. Analisis harga: yfinance menghitung CAR terhadap IHSG; data juga bisa diunduh sebagai JSON.

Skor adalah heuristik awal untuk prioritas penelaahan, bukan bukti pelanggaran apa pun. Judul dan kutipan singkat berasal dari RSS; baca artikel aslinya sebelum menyimpulkan.
